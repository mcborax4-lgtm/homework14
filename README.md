# Homework 14 commerce classes

## Описание
Проект реализует базовую структуру для интернет-магазина с использованием ООП. 
Содержит классы для работы с товарами и категориями, а также загрузку данных из JSON.

## Функционал
- Класс `Product` для создания товаров (название, описание, цена, количество)
- Класс `Category` для создания категорий (название, описание, список товаров)
- Подсчет общего количества категорий и товаров через атрибуты класса
- Загрузка данных из JSON-файла с автоматическим созданием объектов
- Магические методы `__str__` и `__add__` для класса Product
- Магический метод `__str__` для класса Category
- Итератор для перебора товаров в категории

## Класс Product

### Атрибуты
- `name` — название товара
- `description` — описание товара
- `price` — цена товара
- `quantity` — количество на складе

### Методы
- `__str__` — строковое представление:  
  `Название, 50000.0 руб. Остаток: 10 шт.`
- `__add__` — сложение общей стоимости двух товаров:  
  `(price1 * quantity1) + (price2 * quantity2)`
- `new_product` — создание продукта из словаря (с проверкой дубликатов)

## Класс Category

### Атрибуты класса
- `category_count` — общее количество категорий
- `product_count` — общее количество товаров во всех категориях

### Атрибуты экземпляра
- `name` — название категории
- `description` — описание категории
- `__products` — приватный список товаров

### Методы
- `__str__` — строковое представление:  
  `Название категории, количество продуктов: 15 шт.`  
  (сумма quantity всех товаров в категории)
- `add_product` — добавление товара в категорию
- `products` — геттер для получения списка товаров в виде строки
- `__iter__` и `__next__` — возможность перебирать товары в цикле for

## Примеры использования
```python
# Создание продуктов
product1 = Product("Телефон", "Смартфон", 50000.0, 10)
product2 = Product("Ноутбук", "Компьютер", 80000.0, 5)

# Строковое представление
print(product1)  # Телефон, 50000.0 руб. Остаток: 10 шт.

# Сложение общей стоимости
total = product1 + product2  # (50000 * 10) + (80000 * 5) = 900000

# Создание категории
category = Category("Электроника", "Гаджеты", [product1, product2])
print(category)  # Электроника, количество продуктов: 15 шт.

# Перебор товаров в категории
for product in category:
    print(product.name)  # Телефон, Ноутбук

# Загрузка из JSON
categories = load_from_json("data/products.json")
```

## Абстракция и миксины

### 🔹 Абстрактный класс `BaseProduct`
- Находится в `src/abstract_base.py`
- Задаёт обязательные методы для всех продуктов: `__str__`, `__add__`, геттер/сеттер `price`
- Класс `Product` теперь наследуется от `BaseProduct`

### 🔹 Миксин `CreationMixin`
- Находится в `src/mixins.py`
- При создании любого продукта автоматически печатает в консоль:
  ```
  Создан объект Product с параметрами: {...}
  ```
- Добавлен в цепочку наследования класса `Product`

### 🔹 Новые тесты
- `test_product_creation_mixin` — проверяет, что миксин срабатывает
- `test_smartphone_creation_mixin` — проверяет для наследников
- `test_base_product_abstract` — проверяет, что нельзя создать объект абстрактного класса
- `test_product_implements_abstract_methods` — проверяет реализацию всех методов

## Исключения

### 🔹 Проверка количества товара
- При создании товара с `quantity <= 0` выбрасывается `ValueError`
- Сообщение: `Товар с нулевым количеством не может быть добавлен`

### 🔹 Средний ценник категории
- Метод `average_price()` в классе `Category`
- Если в категории нет товаров — возвращает `0.0` (без ошибки)
